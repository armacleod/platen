05 / States

Every state is a token

Hover, active, selected, disabled, and focus are specified. Focus is a 2px ring offset 2px.

StateTokenNote
Hover--accent-hoverFill darkens on sheet, brightens on void

Tab to this link to check the focus ring, then open the dialog above with the keyboard. Motion respects reduced-motion settings.

06 / Access

Constraint, not detail

Targets are 28px minimum for small buttons, 40px standard. The dialog traps focus while open and closes on veil click.

Contrast budget.Body ink on sheet 16.4:1. Ember text 6.8:1. Primary fill with white 5.9:1. Void pairs above 6.5:1. No low-contrast body text ships.

Voice is plain. Empty states state the fact and the next step. Labels are verbs first: Open dialog, Read the ledger, Read the spec.
